Keep Talking and Nobody Explodes CIA Edition Hexadécimal

Sur le sujet de l'Hexadécimal

Aujourd'hui, on a besoin de compétences en design web pour désamorcer une bombe ! Décodez la couleur avant que la bombe explose.

Ce module comporte un écran numérique affichant un code couleur hexadécimal à 6 caractères, ainsi que six boutons colorés.

Règles de Désamorçage

  1. Lisez le code hexadécimal affiché sur l'écran (au format #RRVVBB).
  2. Convertissez les paires de caractères pour estimer la quantité de chaque couleur primaire :
    • RR représente le canal Rouge (00 = min, FF = max).
    • VV représente le canal Vert (00 = min, FF = max).
    • BB représente le canal Bleu (00 = min, FF = max).
  3. Estimez la couleur finale à l'aide des tableaux ci-dessous et trouvez le bouton correspondant.
  4. Appuyez sur le bon bouton coloré pour passer à l'étape suivante.
  5. Répétez ce processus 3 fois au total pour résoudre le module.

Évaluation des Intensités (De 0 à F)

Valeur Hexadécimale Intensité Lumineuse
00 - 3F Très Faible / Éteint
40 - 7F Faible
80 - BF Moyenne
C0 - FF Forte / Maximum

Guide de Mélange des Couleurs

Si plusieurs canaux ont une forte intensité, les couleurs se mélangent (synthèse additive) :

  • Rouge + Vert = Jaune / Orange
  • Rouge + Bleu = Magenta / Rose / Violet
  • Vert + Bleu = Cyan / Turquoise
  • Rouge + Vert + Bleu = Blanc / Gris clair
  • Aucune teinte = Noir / Gris foncé
Astuce : Si un seul canal est très fort (ex: #F12210), la couleur sera pure (ici, un rouge vif). Si toutes les valeurs sont très faibles (ex: #1A2B15), la couleur sera très sombre (proche du noir ou gris foncé).

Note : Appuyer sur un mauvais bouton provoquera une erreur immédiate, mais ne réinitialisera pas votre progression.
