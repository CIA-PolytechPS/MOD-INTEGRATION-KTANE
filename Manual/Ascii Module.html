Keep Talking and Nobody Explodes CIA Edition ASCII

Sur le sujet d'ASCII

Des lettres, des nombres, et du stress. Convertissez correctement chaque caractère avant que la bombe ne vous convertisse en souvenir.

Ce module affiche un mot en minuscules. Convertissez chaque lettre en score en appliquant les règles ci-dessous dans l'ordre, puis entrez la somme totale.

Règles de Désamorçage

  1. Le module affiche un mot en minuscules (a-z).
  2. Pour chaque lettre, appliquez la première règle valide dans la table de priorité.
  3. Additionnez les scores de toutes les lettres du mot.
  4. Entrez la somme sur le module, puis validez avec le button à droite.
  5. Répétez ce processus 3 fois pour résoudre le module.
Important : Les codes ASCII utilisés sont ceux des lettres minuscules : a = 97 à z = 122.

Table des Règles (Priorité décroissante)

Pour chaque lettre du mot, suivez cette liste de haut en bas :

# Condition (sur la lettre) Score
1 Si la lettre est a ou e +15
2 Sinon, si la lettre est une voyelle : a, e, i, o, u, y +11
3 Sinon, si la lettre est b, d ou e +7
4 Sinon, si la lettre est dans le mot "polytech" +5
5 Sinon, si la lettre est dans le mot "examen" -10
6 Sinon, si la lettre est dans le mot "informatique" +20
7 Sinon Code ASCII de la lettre

Bonus/Malus de Mot (en plus de la somme des lettres)

Après avoir obtenu le score de chaque lettre, appliquez les Bonus/Malus suivant, qui ne sont valides qu'une seule par mot :

  • Si le mot contient au moins 3 voyelles : +8
  • Si le mot contient au moins 2 fois la même lettre : -5 (non cumulable, valide une fois par mot)
  • Si la première et la dernière lettre sont identiques : +12
  • Si le mot a une longueur paire : +4, sinon : -3

Exemple de Calcul

Mot affiché : codes

  • c → règle #4 (polytech) = +5
  • o → règle #2 (voyelle) = +11
  • d → règle #3 (bde) = +7
  • e → règle #1 (a/e) = +15
  • s → règle #7 (ascii) = +115

Sommes des scores des lettres modulo 100 = ( 5 + 11 + 7 + 15 + 115 ) % 100 = 153 % 100 = 53

Sans oublier les Bonus/Malus du mot :

  • Voyelles : 2 → pas de +8 : 0
  • Lettres répétées : non → pas de -5 : 0
  • Première = dernière ? non : 0
  • Longueur 5 (impaire) → -3

Total final = 53 + 0 + 0 + 0 - 3 = 50

Note : Une entrée incorrecte provoque une erreur immédiate, mais ne réinitialise pas les étapes déjà validées.
