Sur le sujet des Caractères de Code

On dirait qu'un développeur frustré a tenté d'écrire un script de désamorçage. Pour l'amour du clean code, ne ratez pas votre syntaxe.

Ce module comporte un pavé de quatre boutons, chacun affichant un caractère de programmation unique.

Règles de Désamorçage

  1. Trouvez la colonne ci-dessous qui contient les quatre caractères affichés sur les boutons du module.
  2. Une seule colonne correspondra aux quatre symboles présents sur le module.
  3. Appuyez sur les quatre boutons dans l'ordre où ils apparaissent de haut en bas dans cette colonne spécifique.
  4. Appuyer sur un bouton hors de cet ordre provoquera une erreur immédiate et réinitialisera la séquence du module.
1 2 3 4 5 6
[ # { ~ ( #
# ( ) _ $ &
_ } \ & * }
& \ / [ ^ ;
$ ! ^ | § .
| £ § , £ <
~ * . > ) /
Note pour l'Expert : Les colonnes ne partagent pas toutes les mêmes symboles, mais certains caractères reviennent fréquemment. Décrivez précisément les paires de parenthèses ( ), crochets [ ] et accolades { } pour éviter toute confusion.
